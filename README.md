# あと少しで承認

「ボールペン1本の購入」の稟議書を承認してもらうため、上司に催促し続けるゲーム。
いつまで経っても承認が終わらないように見せかけて、意地になって催促し続けた人だけが本当に承認にたどり着ける。

## 遊び方

`index.html` をブラウザ(Chrome や Safari)で開いて、「催促する」を押し続けるだけ。
PC、スマホの縦向き・横向きのどれでも遊べる。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| index.html | 画面の骨組み(稟議書画面、確認ダイアログ、エンディング) |
| style.css | 見た目(色・大きさ・アニメーション) |
| game.js | ゲームの動き。冒頭に調整用の「設定」がまとまっている |

## 進み方の仕組み

1. **クリアは「押した回数」で決まる。** 押した回数が、その稟議で決まった回数(700〜1200回のどれか)に届いた瞬間に必ず承認される。差し戻しや意地悪でクリアが遅れることはない。
   - 数えるもの: 本物の「催促する」ボタン(意地悪の最中も含む)と、偽ボタンのクリック
   - 数えないもの: 確認ダイアログの「はい・いいえ」と、演出中(偽の承認など)で押せない時間のクリック
2. **差し戻しは画面の%だけを下げる。** 差し戻されると「遅れ」がたまり、画面の%がはっきり下がる。ただし押した回数は減らないので、クリアには影響しない。
3. **クリアが近づくと差し戻しの影響が薄まる。** 押した回数が `SETBACK_FADE_FROM`(70%)を超えると「遅れ」の効き目が少しずつ弱まり、最後はゼロになる。そのため表示は 99.9% → 99.99% → … と自然に100%直前まで近づき、急に100%へ飛ぶことはない。
4. **承認前に100%と表示されることはない。** 「残り」を切り上げてから計算しているため(わざと見せる「偽の承認」演出は除く)。
5. 承認者(係長 → 課長 → … → 社長 → 会長 → 創業者の銅像)は、画面の%と同じ進み具合で上がっていく。差し戻されると下の役職に戻ることもある。

## 設定(game.js の冒頭)

| 名前 | 内容 | 今の値 |
| --- | --- | --- |
| `CLEAR_CLICKS_MIN` / `CLEAR_CLICKS_MAX` | 承認に必要な押した回数の範囲。新しい稟議を出すたびにこの範囲からランダムに決まる(再読み込みしても変わらない)。試すときは両方を200にすると短く遊べる | 700〜1200 |
| `EVENT_CHANCES` | 意地悪の発生確率(押した回数の進み具合ごと) | 20%まで3% / 40%まで8% / 60%まで10% / それ以降12% |
| `SETBACK` | 差し戻しで画面の%を戻す量(イベントごと) | 2〜4% など |
| `SETBACK_FADE_FROM` | 差し戻しの影響が薄まり始めるタイミング | 押した回数の70% |
| `FAKE_APPROVAL_FROM` | 「偽の承認」が出始める進捗(画面の%) | 70% |
| `APPROVERS` | 承認ルートの役職リスト | 係長〜創業者の銅像 |

## 意地悪イベント(10種類)

意地悪は「くじ引きの引いたら戻さない」方式で選ぶので、10種類すべてが1回ずつ出るまで同じものは出ない。
さらに、まだ見ていない意地悪が残ったまま承認が近づくと、必ず意地悪が起きるようにしてあるため、1回のプレイで10種類すべてを見られる。

| イベント | 内容 |
| --- | --- |
| コーヒー事件 | 部長が書類にコーヒーをこぼして、差し戻される |
| 課長が逃げる | 催促ボタンが画面中を逃げ回る |
| 差し戻し期間 | しばらく押すほど差し戻される |
| 偽の承認 | 約1.5秒「100%・ゲージ満タン」と見せかけて「前のバージョンの書類でした」。進捗70%以上のときだけ出る |
| 押印欄不足 | 様式変更で再提出になり、差し戻される |
| 経費削減 | 発生した瞬間にボタンが縮み、押すたびに 18 → 14 → 10 → 8 → 6px(豆粒サイズ)と小さくなる。5回目で元に戻る |
| 書類の山 | 偽ボタンが大量発生。画面をマス目に区切って配置するので、ボタン同士は重ならない。偽物を押すと差し戻される |
| 逆さま運用 | 社長の意向で画面が上下逆さまになる |
| ペーパーレス化 | ボタンが透明になる |
| しつこい確認 | 4回確認される。はい・いいえの位置が入れ替わる |

画面の回転やウィンドウの大きさが変わったときは、逃げているボタンや偽ボタンを画面内に置き直す。

## エンディング

承認されると、大きな「承認」のハンコが押され、紙吹雪の中で長文の褒め言葉(7段落)が順番に表示される(新しい行が出るたびに自動でスクロールする)。
社内七不思議、ほほえむ銅像、人事部の評価シート、出版社からの執筆依頼、催促王定食、南極からの祝電など、やりすぎなくらい大げさに褒めちぎる。
実績「伝説の催促王」のあと、小さく「なお、ボールペンは在庫切れのため購入できませんでした。」と出て終わる。
待ちきれない人は、エンディング画面をタップすると残りの文章が一気に全部表示される。
(出てくる前の透明なボタンを押してしまっても反応せず、全文表示になるだけ)
最後に「結果を X でシェアする」ボタンで、催促した回数とかかった時間を投稿できる。公開したページで遊んだ場合は、ゲームのURLも付く。

## その他の仕組み

- **途中経過の保存**: 押した回数や差し戻しの状態を、ブラウザの localStorage(ブラウザの中にある小さな保存場所)に保存する。再読み込みしたり閉じたりしても、同じブラウザなら続きから遊べる。承認されるか「もう一度稟議を出す」を押すと保存は消える。
- **長押し対策**: キーを押しっぱなしにしたときの連続入力は無視する(Enter キー長押しでの自動連打を防ぐ)。
- **リンクの見た目**: SNS や検索結果に出るタイトル・説明文を設定済み。タブのアイコンは赤い「承」のハンコ。
